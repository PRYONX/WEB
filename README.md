# PRYONX | Custom AI Solutions & AI Automation

PRYONX builds custom AI solutions, intelligent automation, AI-powered products, and AI voice agents designed around real business requirements.

## Tech Stack

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- Framer Motion
- React Router 6
- Lucide React icons

## Getting Started

```bash
# install dependencies
npm install

# start the dev server
npm run dev

# build for production
npm run build

# preview the production build
npm run preview
```

## Project Structure

```
src/
├── components/   # layout, UI & section components
├── pages/        # Home, Services, Solutions, About, HowWeWork, Contact
├── hooks/        # custom React hooks
├── data/         # site content data
├── styles/       # global styles
└── utils/        # helpers
```

## Deployment

Configured for Vercel via `vercel.json` (framework: vite, SPA rewrites).
